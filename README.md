# 生命之境 · Lifeverse

生命之境是一个在浏览器里运行的生态模拟沙盒。苔湾群岛有苔叶兽、琥脊兽、棘冠兽、潮鳍兽和影爪兽。草地、丘陵和浅滩提供不同的觅食条件。捕食、气候和资源共同影响哪些个体能留下后代，后代继承性状并发生有限变异。

## 游玩

- 拖动地图旋转视角，用滚轮或地图按钮缩放。点击生物或使用个体面板的编号下拉框查看性状。
- 打开「九区图册」，为九个地块分别选择地貌与种子。用「新建单区」进入选中的地块，培育后保存到该槽。拼合时每个地块可选已有存档或新生成。拼合后的地图是 3×3 个完整地块，陆桥相连。点击区块可聚焦并调整本区气候，整图可以独立存档。
- 在个体面板让幼体立即成熟、补满能量，或将遗传适温和偏好湿度调向当地环境。恩赐结果显示在按钮下方。追踪个体后，可在血脉面板观察它的后代及其体型分支。
- 在个体和血脉面板查看陆行足、涉水蹼、游水鳍和翼的遗传变化。滑翔翼可沿下坡移动得更远，飞行翼可越海。分化图可追踪飞行、水生和气候分支，也会标记灭绝物种与继替它的后代。
- 「分化与干预」可以为成年个体繁育幼体、投放种群，以及将个体迁到另一地块。「延续这条血脉」从在世成员选择繁育亲本。全族死亡后，可用遗传档案复育曾达到的最高世代。
- 在环境面板调整气温和降水，再用 48× 观察几代。调节降水后，长期降水会逐渐变化。相同种子下，干湿环境可能留下不同血脉。可用空格暂停，暂停后可单步推进。
- 九个地块和拼合世界的存档保存在当前浏览器的 IndexedDB。旧九区存档可直接读取。旧附肢版的单槽存档可在图册读取和参与拼合。读取和拼合后世界暂停。

第 1 代指创始个体，每次繁殖产生比父代高一代的后代。48× 控制世界时间推进速度。亲本和后代连续保有新的气候适应或行动形态时，可以形成独立演化分支。物种灭绝后，仍能繁殖的血脉有机会产生继替物种。详见[演化规则](docs/EVOLUTION.md)与[路线图](docs/ROADMAP.md)。

## 本地运行

使用 Node.js 22.18 或更高版本及 `package.json` 声明的 pnpm 版本。仓库的 CI 使用 Node.js 24。

```sh
git clone https://github.com/chunrizizhijie-png/lifeverse.git
cd lifeverse
pnpm install --frozen-lockfile
pnpm dev
```

在浏览器打开终端打印的本地地址。生产构建输出在 `dist/`。

```sh
pnpm check
pnpm test
pnpm build
pnpm preview
```
