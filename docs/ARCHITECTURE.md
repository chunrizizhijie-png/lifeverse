# 项目结构

| 路径 | 职责 |
| --- | --- |
| `src/sim/terrain.ts` | 从种子生成地形、陆地与浅水范围、局部湿度及资源格 |
| `src/sim/ecology.ts` | 定义生态角色的初始性状、觅食效率、捕食对象与遗传体型分支 |
| `src/sim/world.ts` | 推进模拟、处理干预、采样种群、保存与读取状态 |
| `src/sim/types.ts` | 定义世界状态和 Worker 消息 |
| `src/sim/worker.ts` | 调度固定时间步，执行操作，发送帧或存档 |
| `src/render/` | 地形、水面、生物实例、镜头与平面备用视图 |
| `src/main.ts`、`src/ui/` | 界面输入、状态显示、种群图表和浏览器存档 |
| `tests/` | 运行可复现的模拟与存档测试 |

主线程把操作发送给 Worker，Worker 在推进或处理操作后发回快照。三维视图只对快照间的位置做视觉插值，模拟中的位置、能量和性状保留在 Worker 中。地图与 Worker 使用同一个地形生成模块。

存档版本 3 增加地块种子和地貌、各区气候、分化树、多个血脉及遗传档案。读取 v1 时将旧资源格放到扩大后地图的对应位置并补齐湿度性状。读取 v1 或 v2 时保留个体和谱系，补齐祖系编号。图册使用 IndexedDB 的九个单区槽和一个整图槽，旧单槽作为第一区的读取来源。

拼合将九个单区的坐标、资源和生物迁入共同网格，重映射个体及谱系编号并对齐各区时间线。合图种群曲线从拼合时开始采样。源存档保留各自的历史与随机状态。

Three.js 的运行环境缺少 WebGL 2 时，界面用平面视图呈现同一个模拟。
