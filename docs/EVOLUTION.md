# Alpha 0.1 的演化规则（含足 / 蹼 / 鳍进化链）

- 苔叶兽采食陆地植物与水域藻类，琥脊兽在能量较低时寻找可通行范围内的猎物，靠近后有机会捕获。苔叶兽发现邻近饥饿捕食者时尝试逃离。
- 附肢演化链由遗传性状 `aquatic`（`0 ~ 1`）驱动，分为三个离散形态阶段：
  - **陆行足 (`foot`, `0.00 <= aquatic < 0.35`)**：创世初始种群的陆生形态，仅可在陆地（`height >= 0.55`）行动，陆地移速 `1.05x` 且陆行代谢最低，但无法进入浅滩与深水。
  - **涉水蹼 (`webbed`, `0.35 <= aquatic < 0.70`)**：由陆行足后代经有界变异涌现的半水生过渡形态，可涉过祖先无法进入的浅滩水域（`-2.4 <= height < 0.55`）及陆地，浅滩移速 `1.14x`、陆地移速 `0.93x`，水陆两栖取食。
  - **游水鳍 (`fin`, `0.70 <= aquatic <= 1.00`)**：由涉水蹼后代继续变异演化的水生形态，可进入深水、浅滩与低岸（`-12 <= height <= 1.85`），水中移速 `1.38x`、水藻采食效率最高且水中代谢能耗最低，但在岸滩陆地移速仅 `0.56x` 且脱水能耗较高。
- 陆地与水域各有独立的资源格与再生速率。温暖丰水环境加速浅滩与海域水藻再生并降低水生散热损耗，推动种群向涉水蹼与游水鳍演化。寒冷干旱环境抑制水藻再生并增大冷水热损耗，使陆行足在内陆草甸维持优势。
- 成熟、能量足够且繁殖冷却结束的个体有机会繁殖。出生会消耗父代能量。新个体携带带有有界扰动的父代性状。
- 体型、色相、冠饰与附肢形态（足柱、扇形趾蹼与尾桨、流线胸腹鳍与背尾鳍）在三维岛屿、平面视图与观察画像中均有可见外观差异。
- 血脉面板支持追踪任一始祖，并对照始祖与后代的附肢形态、水生度、陆水移速能力、适温与世代跨度。
- 促生影响成熟进程，恢复补充当前能量。调适修改可遗传的适温，每次最多改变 3°C，方向由局部气温决定。
- 种群上限为 180，谱系档案保留最多 2,200 条记录。档案保留在世个体和标记的始祖，并优先保留标记血脉的记录。血脉面板会标明仍可追溯的进化片段。

相同种子、相同推进步数及同一时间步上的相同操作可用于复现。实时点击时间取决于玩家输入到达 Worker 的时刻。需要精确复现操作时使用暂停与单步。
