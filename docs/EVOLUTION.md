# Alpha 0.1 的演化规则

- 苔叶兽在陆地移动并消耗资源格中的植物。琥脊兽在能量较低时寻找猎物，靠近后有机会捕获。苔叶兽发现邻近饥饿捕食者时尝试逃离。
- 移速和体型影响移动或能耗，海拔会修正局部气温。气温偏离适温会提高能耗，降水控制植物再生速率。
- 成熟、能量足够且繁殖冷却结束的个体有机会繁殖。出生会消耗父代能量。新个体携带带有有界扰动的父代性状。
- 体型、色相、冠饰和身体比例反映遗传性状。两种生态角色的摄食方式由其角色决定。
- 促生影响成熟进程，恢复补充当前能量。调适修改可遗传的适温，每次最多改变 3°C，方向由局部气温决定。
- 种群上限为 180，谱系档案保留最多 2,200 条记录。被标记的血脉会继续追踪，在世个体和标记的根节点保留。后来才标记的个体，只能依据保留的谱系记录回溯既有后代。

相同种子、相同推进步数及同一时间步上的相同操作可用于复现。实时点击时间取决于玩家输入到达 Worker 的时刻。需要精确复现操作时使用暂停与单步。
