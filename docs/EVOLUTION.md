# 演化规则

## 栖息地与食物

| 生态角色 | 主要食物或猎物 |
| --- | --- |
| 苔叶兽 | 草地和林地植物 |
| 棘冠兽 | 丘陵和林地植物 |
| 潮鳍兽 | 沿岸和浅水植物 |
| 琥脊兽 | 苔叶兽、棘冠兽 |
| 影爪兽 | 潮鳍兽、棘冠兽，缺少猎物时补食植物 |

三类植食兽可能消耗同一格的植物，但在不同栖息地的采食效率有差异。琥脊兽偏好苔叶兽，影爪兽偏好潮鳍兽，两者都可能追猎棘冠兽。植食兽遇到能捕食自己的饥饿捕食者时会尝试逃离。潮鳍兽和湿地型可进入浅滩。影爪兽也能涉水追击，但在浅滩移动较慢。

## 气候与遗传

- 海拔影响局部气温。降水和地形共同影响局部湿度，浅滩比高处湿润。长期降水逐步跟随设定值并影响植物再生。
- 气温、湿度偏离个体的遗传适温和偏好湿度时，个体的能耗会上升。气候持续变化时，能耗低的个体更可能积累足够能量并留下后代。
- 成熟、能量足够且繁殖冷却结束的个体有机会繁殖。出生消耗父代能量，后代继承父代性状并发生有限变异。第 1 代是创始个体，后代比父代高一代。
- 湿地型可涉入浅水，旱地型在较干的环境中承受较低的湿度能耗。分化图按遗传适温（低于等于 16°C、温和、高于等于 28°C）和适湿（低于等于 38%、中湿、高于等于 76%）组合分类。亲本和幼体处于同一新的非温和中湿区间时会形成或加入对应子分支。分支分别统计存活个体，保留灭绝分支的历史。
- 单区种群上限为 180，九区世界上限为 1,620。每区的拥挤度影响当地繁殖。已追踪血脉会继续记下新出生的后代，创始个体死亡后仍能查在世后代和累计世代。追踪过的创始个体保留遗传档案，早期已经清理的未追踪祖先记录无法补回。

## 造物主恩赐

- 促生使幼体立即成年、解除繁殖冷却并补充最多 20 点能量。
- 恢复把选中个体的能量补满至 100。
- 调适将可遗传的适温和偏好湿度向当地环境调整。每次最多调整 8°C 和 24 个百分点。个体面板显示操作前后的性状与环境能耗。
- 定向繁育直接增加 1–6 只幼体，可选择继承亲本性状或培育特定温湿组合。血脉繁育优先选用符合方向的成年成员，全族死亡时可使用遗传档案。投放种群加入一批创始个体，迁移把选中的个体带到其他区。

相同种子、相同推进步数及同一时间步上的相同操作可用于复现。实时点击时间取决于玩家输入到达 Worker 的时刻。需要精确复现操作时使用暂停与单步。
